# Fora de agora e gatilhos

O que ficou fora desta versão e o sinal que justificaria trazer cada item de volta.

| Item | Gatilho para reconsiderar |
|---|---|
| Ficha de saúde / anotações | pedido recorrente **e** parecer jurídico sobre dado sensível |
| Importar contatos | profissionais com mais de 50 clientes desistindo no cadastro |
| Push / PWA obrigatório | evidência de que lembretes esquecidos causam faltas |
| Exportação/exclusão no app | volume de pedidos LGPD que tome mais de 1 h/mês |
| API WhatsApp / automação | receita que pague o custo por mensagem + número dedicado |
| Pagamento integrado | não previsto: entrevistas indicam baixo interesse |
| Página A/B / marketing | depois de validar retenção com os primeiros usuários |
| Clientes fora do Brasil | primeiro pedido real |

## Antes de ampliar

A síntese do discovery recomendou **validar com profissionais reais antes de investir mais**. Esta versão existe para esse teste: coloque nas mãos de 5 a 10 massoterapeutas e meça se elas continuam usando após 4 semanas.
